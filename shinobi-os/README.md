# SHINOBI OS ⚡

A high-performance cyberpunk/ninja web operating system template for [web-templates-hub](https://github.com/priyansudas07/web-templates-hub).

## 🚀 Tech Stack
- **React 19**
- **TypeScript 6**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Framer Motion**

## 🛠️ Getting Started

```bash
cd shinobi-os
npm install
npm run dev
```
